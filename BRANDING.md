# MCM brand palette (classic / live GitHub Pages)

Restyled September 2026 to match the existing MCM brand while keeping the modern asset-management & advisory IA/copy.

## Palette hex values used

| Role | Hex | Notes |
|------|-----|--------|
| Primary green | `#5d8f00` | Links accents historically; primary CTAs, eyebrows, nav CTA, focus |
| Green hover | `#4a7300` | Primary button / CTA hover |
| Forest green (logo/nav) | `#2f5c28` | Headings, logo text, strong brand type |
| Mid forest green | `#317b2e` | Nav links |
| Accent burgundy | `#a30000` | Secondary accents, card `h3`, body links |
| Burgundy hover | `#7a0000` | Link hover |
| Dark olive | `#36352d` | Footer panel background |
| Soft khaki | `#bcb98e` | Footer name / link text |
| Body text | `#666666` | Body copy on light backgrounds |
| Strong text | `#2a2a2a` | Emphasized body / labels |
| Soft muted | `#8a8888` | Optional / muted notes |
| Footer muted | `#a9a7a7` | Footer meta and disclaimer |
| Page background | `#ffffff` | Main content |
| Warm light gray | `#f7f6f2` / `#f0efe9` | Hero / alternating sections |
| Borders | `#e2e0d8` / `#cfcab8` | Cards and dividers |
